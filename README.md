# 双色球走势分析与智能选号工具

一套基于历史开奖数据（走势）做统计分析与号码生成的 Python 工具。支持**纯随机**与**按走势加权**（追热 / 博冷 / 冷热均衡）两种思路，可一键生成**指定注数**的号码，并自动校验规则、注间去重。

> ⚠️ **理性购彩提示**
> 双色球每期开奖是**独立**的均匀随机抽样，历史号码**不影响**未来结果。本工具的「走势分析」与「加权选号」只是一种**按统计偏好生成号码**的娱乐/参考方式，**不会提高中奖概率**。请量力而行，理性购彩。

## 快速开始

```bash
# 1) 更新/拉取最新真实历史数据（可选，默认已有 300 期）
python fetch_data.py 300

# 2) 随机生成 5 注
python cli.py -n 5

# 3) 基于走势「追热」生成 10 注
python cli.py -n 10 -s hot

# 4) 查看走势摘要 + 「冷热均衡」生成 8 注
python cli.py -n 8 -s balanced --summary

# 5) 生成 20 注并输出 JSON（方便接入其他系统）
python cli.py -n 20 -s cold --json

# 6) 运行内置自检（校验规则/注数/去重/策略）
python cli.py --self-test
```

## CLI 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-n, --count` | 生成注数 | 5 |
| `-s, --strategy` | `random`(随机) / `hot`(追热) / `cold`(博冷) / `balanced`(均衡) | `random` |
| `-d, --data` | 历史数据 CSV 路径（`hot/cold/balanced` 需要） | `data/sample_history.csv` |
| `--no-dedupe` | 关闭整注去重 | 关（默认去重） |
| `--summary` | 打印走势摘要 | 关 |
| `--json` | JSON 格式输出 | 关 |
| `--self-test` | 运行内置自检 | —— |

> `random` 策略不需要历史数据；`hot/cold/balanced` 必须提供历史数据文件。

## 算法说明

### 1. 走势分析（基于历史开奖数据）
- **频率**：某号码在历史中出现次数。越高越「热」。
- **遗漏**：距离最近一次出现已过去的期数。越大越「冷」。
- **冷热分档**：按频率三等分，标记 热 / 温 / 冷。
- **区间分布**：红球 33 个均分 3 区（01-11 / 12-22 / 23-33），统计各区占比，辅助判断区间冷热。

### 2. 选号策略
| 策略 | 逻辑 | 适用偏好 |
|------|------|----------|
| `random` | 红球 1-33 随机不重复取 6，蓝球 1-16 取 1 | 完全随机 |
| `hot` | 按频率加权抽样，越热越容易被选中 | 追近期热门号 |
| `cold` | 按遗漏加权（遗漏越大权重越高），偏冷门号 | 博冷门回补 |
| `balanced` | 频率 × 遗漏综合加权 | 冷热兼顾 |

加权抽样采用 **Efraimidis–Spirakis** 无放回加权算法，保证红球 6 个不重复、蓝球 1 个，且每注严格符合双色球规则（红 1-33、蓝 1-16）。

### 3. 生成与去重
- 多注之间按「红球组合 + 蓝球」整注去重，避免重复注。
- 注数过大导致去重空间不足时自动放宽补齐。

## 作为库调用

```python
from ssq import generate_numbers

# 基于历史数据追热生成 5 注
draws = generate_numbers("data/sample_history.csv", count=5, strategy="hot")
for d in draws:
    print(d.formatted())   # 例如：04 06 10 18 23 31  + 04
```

## 数据格式

`data/sample_history.csv` 列：`issue,date,red,blue`
```
issue,date,red,blue
26087,2026-07-30,04,06,10,18,23,31,04
26086,2026-07-28,02,05,14,25,30,32,02
```
> 也可使用拆列写法：`issue,date,red1,red2,...,red6,blue`。
> 想用自己的数据，只需按此格式导出/粘贴后指定 `-d` 即可。
